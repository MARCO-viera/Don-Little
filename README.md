# 🍗 Don Little

Aplicación web para una pollería, desarrollada inicialmente como proyecto académico grupal y posteriormente **mejorada y reorganizada como proyecto de portafolio personal**.

La versión actual incorpora mejoras en la estructura del frontend, organización del código JavaScript y gestión dinámica de productos, promociones y locales.

## 👨‍💻 Autor

Técnico en Computación e Informática — Cibertec

## ▶️ Ejecución

1. Clonar el repositorio.
2. Abrir el proyecto en Visual Studio Code.
3. Ejecutar `index.html` en el navegador.

La versión actual corresponde al frontend y no requiere instalación de dependencias ni servidor para ejecutarse.

## 🔧 Mejoras realizadas

A partir de la versión académica original se realizaron mejoras orientadas a convertir el proyecto en una aplicación más organizada y presentable:

* Reorganización del código frontend.
* Separación de los datos de productos y locales.
* Renderizado dinámico de información mediante JavaScript.
* Implementación y mejora del carrito de compras.
* Persistencia de información mediante LocalStorage.
* Implementación del contador del carrito.
* Mejora de la estructura y organización de las páginas.
* Adaptación del proyecto para su presentación como portafolio.
